# Kelvin — Pharma claims recovery agent

From temperature excursion to recovered money. Kelvin collects the logger data and shipping documents, rebuilds who held the cargo when it got warm, finds who should pay and by when, drafts the evidence pack and claim letter, and follows up after a manager approves. Quality keeps the product decision; a manager approves every claim.

> Decision support for a university demo. Not legal advice.

## Run locally

```bash
npm install
cp .env.example .env.local   # add your model API key
npm run dev                  # http://localhost:3000
```

| Script | What it does |
|---|---|
| `npm run dev` | Dev server (Webpack, see AGENTS.md) |

| `npm run typecheck` | `tsc --noEmit` |

## Data

- **Local mode (default):** embedded Postgres (PGlite) in `.data/pglite`, documents in `.data/files`. No setup needed; migrations run on first use.
- **Supabase mode:** set `DB_MODE=supabase` and `DATABASE_URL` (milestone 8).
- **Safety in the database itself:** `audit_events` rejects UPDATE/DELETE (trigger); an outgoing Outbox row must reference an approval decision (CHECK constraint).

## Demo cases

Generated by `seed/` from typed specs (`seed/cases/demo.ts`): 5-minute logger CSV, air waybill, handling events JSON, handling report, forwarder contract (numbered clauses, 3 pages), cargo policy, commercial invoice and 2–3 emails. All dates are relative to the moment of seeding, so **reset the demo on demo day** and the deadlines count down correctly.
