# Kelvin — Pharma claims recovery agent

From temperature excursion to recovered money. Kelvin collects the logger data and shipping documents, rebuilds who held the cargo when it got warm, finds who should pay and by when, drafts the evidence pack and claim letter, and follows up after a manager approves. Quality keeps the product decision; a manager approves every claim.

> Decision support for a university demo. Not legal advice.

## Run locally

```bash
npm install
cp .env.example .env.local   # add your model API key
npm run dev                  # http://localhost:3000
```

## Public demo (Vercel)

On Vercel (`VERCEL` is set) the app runs in **public-demo mode**: the embedded database lives in `/tmp` and is seeded with cases A, B and C automatically when it starts empty, so no database or secrets are needed. Data is per server instance and resets after a cold start. Add `ANTHROPIC_API_KEY` in the Vercel project settings to switch the agent from the deterministic planner to the live model. Run the same mode locally with `npm run build && npm run start:demo` (port 3200).

## Data

- **Local mode (default):** embedded Postgres (PGlite) in `.data/pglite`, documents in `.data/files`. No setup needed; migrations run on first use.
- **Supabase mode:** set `DB_MODE=supabase` and `DATABASE_URL` (milestone 8).
- **Safety in the database itself:** `audit_events` rejects UPDATE/DELETE (trigger); an outgoing Outbox row must reference an approval decision (CHECK constraint).

## How the agent works

- **Orchestrator** (`lib/agent/orchestrator.ts`): Vercel AI SDK `streamText` with 14 Zod-typed tools (`lib/agent/tools/`). Provider and model from env (`AI_PROVIDER=anthropic|openrouter`, `AI_MODEL`, default `claude-opus-5-5`, `AI_EFFORT`). Without a key it falls back to a **deterministic planner** (`lib/agent/script.ts`) that calls the same tools in a fixed order.
- **Rules, not prompts** (`lib/rules/`): Montreal 26 SDR/kg cap and Art. 31/35 periods, contract caps, insured value minus deductible, route ranking by expected €, early (protective) notice threshold. The SDR rate and thresholds are editable in Settings. Unit-tested.
- **Shared case record** (`cases.record`): excursions, custody, clauses, liability, deadlines, ranking and a **citation registry**. Letters cite registry ids like `[S7]`; uncited paragraphs are flagged as assumptions.
- **Status machine** (`lib/case/status-machine.ts`) enforced in code; the orchestrator moves status after each run from the record, so the model cannot skip a gate.
- **Human gates** (`lib/case/gates.ts`): QA disposition (QA role only) and manager approval (manager role only), each with name and timestamp in the audit log.
- **Nothing leaves the app**: `send_via_outbox` refuses without an approval decision, and the database rejects an outgoing Outbox row without one.
- **Audit**: every tool call (input, output, model, duration) is appended to `audit_events`; every run is recorded to `.data/recordings` and, for demo cases, `demo/recordings/<case>-<kind>.json` for Replay mode.
